# Carte Arma 3 interactive — JSON public

Les points sont lus depuis `points.json`.

## Utilisation
- Le site charge automatiquement `points.json`.
- Ajoute/modifie/supprime les points depuis l'interface.
- Clique sur `Exporter` pour générer le nouveau `points.json`.
- Remplace ensuite l'ancien `points.json` sur GitHub Pages.
- Tous les visiteurs voient alors la même liste publique.

## Marqueurs
Les marqueurs sont plus petits et leur taille visuelle reste constante pendant le zoom :
la carte grossit/rétrécit, mais pas les boutons.
